# 0017_lung_lung-point2

Based on the analysis of the sequential frames:

**Observation:**
- **B-mode (top half):** The images show a bright, horizontal echogenic line which represents the pleural line. The chest wall tissues are visible above it.
- **M-mode (bottom half):** The M-mode trace displays a distinct pattern. Above the pleural line (approx. 1.5 cm depth), there are parallel, horizontal lines representing the static chest wall tissues. Below the pleural line, the pattern changes drastically to a granular, "sandy" or speckled appearance. This contrasts with the clean horizontal lines above.
- **Pattern Identification:** This specific pattern—horizontal lines above the pleural line (representing the "beach") and a granular texture below (representing the moving "sea" of lung parenchyma)—is known as the **Seashore sign**.
- **Motion:** Although the frames appear similar, the M-mode texture indicates that the lung tissue below the pleura is moving relative to the probe, creating the granular effect. If sliding were absent (as in a pneumothorax), the area below the pleural line would also show horizontal lines, creating a "Stratosphere" or "Barcode" sign.

**Conclusion:**
The presence of the **Seashore sign** indicates that **pleural sliding is present**.

# 0017_lung_lung-point2

Based on the analysis of the sequential frames:

**Frame-by-Frame Analysis:**
*   **B-mode (Top):** The pleural line is visible as a bright, horizontal echogenic line.
*   **M-mode (Bottom):** In every frame, the M-mode tracing displays a classic **seashore sign**. Above the pleural line, there are horizontal striations representing the static chest wall. Below the pleural line, there is a granular, "sandy" pattern (speckle).
*   **Motion:** Comparing the frames, the granular speckle pattern below the pleural line changes slightly from one frame to the next. This variation indicates the movement of the visceral pleura against the parietal pleura.

**Conclusion:**
The presence of the granular "sandy" pattern below the pleural line on M-mode (the seashore sign) and the changing speckle pattern between frames confirms the presence of lung movement.

**Pleural sliding is present.**

# 0035_lung_unexpected-jellyfish

Based on the provided ultrasound images, the following observations can be made:

1.  **Effusion signs**: There is a large, prominent anechoic (black) space visible in the center of the image. In the context of a lung ultrasound, this represents a significant pleural effusion.
2.  **Consolidation signs**: Adjacent to the fluid collection, there is a large area of highly echogenic, solid-appearing tissue. This area exhibits **tissue-like hepatization**, as it lacks the normal aeration artifacts and resembles the texture of liver tissue.
3.  **Shred sign**: The border between the anechoic fluid collection and the hepatized consolidated lung is irregular and "shredded," which is a classic indicator of the interface between consolidated and aerated lung.

Because both significant fluid collection (effusion) and hepatized lung (consolidation) are clearly visible, the pattern is classified as a PLAPS pattern.

plaps = true

# 0014_lung_septated-pleural-effusion

The ultrasound image shows a large anechoic (black) area in the posterior/lateral dependent zone, consistent with a significant pleural effusion. Within this fluid collection, there is a prominent, undulating, and floating echogenic structure. This is a classic **jellyfish sign**, which represents atelectatic lung tissue floating within the effusion. The solid, echogenic appearance of this floating tissue also demonstrates **tissue-like hepatization** (consolidation).

Because both a large pleural effusion and consolidated/atelectatic lung tissue (the jellyfish sign) are clearly visible, the pattern is classified as both.

**Conclusion:**
plaps = true
type = both

# 0058_lung_pneumonia

The ultrasound images show several characteristic signs of a **PLAPS (Posterolateral Alveolar and/or Pleural Syndrome)** pattern in the posterior/lateral lung zone:

1.  **Effusion signs**: There is a large anechoic (black) space representing a **pleural effusion**. Within this fluid, there is a floating, undulating mass of consolidated lung tissue, which is a classic **jellyfish sign**.
2.  **Consolidation signs**: The lung tissue beneath the pleural line appears solid and echogenic, exhibiting **tissue-like hepatization**. Small, bright hyperechoic dots are visible within this consolidated area, representing **air bronchograms**. The irregular border between the consolidated lung and the fluid also suggests a **shred sign**.

Because both clear pleural effusion features (jellyfish sign) and significant pulmonary consolidation features (hepatization, air bronchograms) are present simultaneously, the pattern is classified as a combination of both.

**Conclusion:**
- **plaps = true**
- **type = "both"**

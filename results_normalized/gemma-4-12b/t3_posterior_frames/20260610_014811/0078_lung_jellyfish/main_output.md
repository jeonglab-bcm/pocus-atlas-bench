# 0078_lung_jellyfish

The sequential images from the lung ultrasound (LUS) show a classic **PLAPS** (Posterolateral Alveolar and/or Pleural Syndrome) pattern in the posterior lung zone.

**Observations:**
- **Effusion signs**: There is a large anechoic (black) area surrounding the lung tissue, indicating a significant **pleural effusion**.
- **Consolidation signs**: Within the fluid collection, there is a visible mass of tissue-like, echogenic lung parenchyma. This tissue is not aerated and has a solid appearance, characteristic of **tissue-like hepatization**.
- **Jellyfish sign**: The hepatized lung mass is floating and undulating within the surrounding fluid collection. This dynamic "jellyfish-like" appearance is a hallmark sign of atelectatic lung tissue submerged in a pleural effusion.
- **Shred sign**: An irregular, shredded deep border is visible where the consolidated lung tissue interfaces with the fluid and potentially some remaining aerated lung.

Based on these observations, the posterior lung zone demonstrates both significant fluid collection and significant alveolar consolidation/atelectasis.

**Conclusion:**
plaps = true
type = "both"

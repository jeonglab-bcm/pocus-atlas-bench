# 0078_lung_jellyfish

The ultrasound images of the posterior lung zone demonstrate a clear **PLAPS pattern**. 

The most prominent feature is a large area of consolidated lung parenchyma that exhibits **tissue-like hepatization**, appearing solid and echogenic similar to liver tissue, with a loss of normal aeration. Within this consolidated area, multiple hyperechoic foci and linear structures are visible, which are characteristic **air bronchograms**. The deep border of this consolidated tissue is irregular, consistent with a **shred sign**.

Additionally, there is a large anechoic (black) space representing a **pleural effusion**. The consolidated lung tissue appears to be floating and undulating within this fluid collection, which is typical of the **jellyfish sign**.

Because both prominent consolidation (hepatization, air bronchograms, shred sign) and pleural effusion (jellyfish sign) are visible, the pattern is classified as both.

**Conclusion:**
plaps = true
type = both

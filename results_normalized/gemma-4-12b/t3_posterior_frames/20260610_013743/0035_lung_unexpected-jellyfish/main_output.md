# 0035_lung_unexpected-jellyfish

In this lung ultrasound (LUS) sequence of the posterior lung zone, the following findings are observed:

*   **Effusion signs**: There is a large, well-defined anechoic (black) space bounded by a pleural line superiorly and a lung line inferiorly, which represents a clear **quad sign**. Within this fluid collection, there is a floating, undulating, and irregularly bordered piece of atelectatic lung tissue, which is a classic **jellyfish sign**.
*   **Consolidation signs**: The floating lung tissue exhibits **tissue-like hepatization**, appearing solid and echogenic rather than aerated.

Based on these observations, both significant pleural effusion and lung consolidation/atelectasis are present.

**Conclusion:**
**plaps = true**
**type = "both"**

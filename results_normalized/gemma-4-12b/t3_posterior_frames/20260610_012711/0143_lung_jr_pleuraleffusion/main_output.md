# 0143_lung_jr_pleuraleffusion

Based on the provided lung ultrasound (LUS) frames of the posterior lung zone, the following observations can be made:

*   **Effusion signs:** A large, prominent anechoic (black) space is visible, which is characteristic of a significant **pleural effusion**. Within this fluid collection, there is a floating, irregular hyperechoic structure that undulates, which is a classic **jellyfish sign**.
*   **Consolidation signs:** The floating structure represents consolidated lung parenchyma. It appears solid and echogenic, exhibiting **tissue-like hepatization**. The border between this consolidated tissue and the surrounding fluid is irregular and "shredded," showing a **shred sign**.

Because both a large pleural effusion and consolidated lung (jellyfish sign) are clearly visible in this posterior dependent zone, the findings meet the criteria for a PLAPS pattern.

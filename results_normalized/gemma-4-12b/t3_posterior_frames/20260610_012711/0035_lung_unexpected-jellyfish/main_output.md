# 0035_lung_unexpected-jellyfish

The ultrasound images demonstrate a classic **PLAPS (Posterolateral Alveolar and/or Pleural Syndrome)** pattern in a posterior lung zone. 

**Observations:**
- **Effusion signs**: There is a large anechoic (black) fluid collection in the dependent zone. Within this collection, there is an irregular, hyperechoic, undulating structure that represents floating, atelectatic lung tissue—a characteristic **jellyfish sign**. The fluid space is bounded by the pleural line superiorly and the lung line inferiorly, creating a **quad sign**.
- **Consolidation signs**: The floating lung tissue exhibits **tissue-like hepatization**, appearing solid and echogenic like liver tissue, indicating significant alveolar consolidation. There is also an irregular, shredded deep border (**shred sign**) between the consolidated and surrounding aerated/fluid areas.

**Conclusion:**
plaps = true
type = both

# 0020_lung_parapneumonic-effusion2

## Lung Ultrasound Analysis — PLAPS Point

---

### Frame-by-Frame Observations

| Finding | Description |
|---|---|
| **Pleural line** | Hyperechoic line visible in the superior near field across all frames |
| **Anechoic space** | Large, predominantly black (anechoic) region occupying the dependent zone — consistent with **free pleural fluid** |
| **Echogenic floating structure** | A bright, wedge/tongue-shaped echogenic mass is visible **within** the anechoic effusion, **changing position and orientation** across sequential frames |
| **Deep border** | The border of the echogenic structure is irregular and shredded in places |
| **Rib shadows** | Lateral acoustic shadows bounding the fluid collection |

---

### Sign Identification

| Sign | Present? | Rationale |
|---|---|---|
| **Quad sign** | ✅ Yes | Anechoic space bounded by pleural line, rib shadows, and lung line |
| **Jellyfish sign** | ✅ Yes | Floating echogenic atelectatic lung undulating within the effusion across frames |
| **Tissue hepatization** | ✅ Yes | The floating lung tissue has liver-like echotexture — atelectatic/consolidated |
| **Shred sign** | ✅ Partial | Irregular deep border of the echogenic lung component |
| **Sinusoid sign** | Likely ✅ | Respiratory movement of lung line toward pleural line (dynamic frames) |

---

### Conclusion

```
plaps  = true
type   = "both"
```

**Rationale:** There is a **large pleural effusion** (anechoic space, quad sign) with a **floating atelectatic/consolidated lung** within it — classic **Jellyfish sign**. The echogenic lung tissue demonstrates hepatization, confirming compressive atelectasis ± consolidation coexisting with the effusion.

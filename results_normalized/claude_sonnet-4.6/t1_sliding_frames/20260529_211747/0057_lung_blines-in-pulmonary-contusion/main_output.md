# 0057_lung_blines-in-pulmonary-contusion

## Frame-by-Frame Analysis

### Frames 1–3
- Pleural line visible at ~2–3 cm depth
- Line appears **relatively smooth and sharply defined** in frames 2–3
- Sub-pleural speckle is present but **minimally variable** between frames
- Faint horizontal echoes (A-lines) forming below the pleural line

### Frames 4–6
- Near-field **increased echogenicity** with brighter, more textured pleural interface
- Sub-pleural speckle pattern shows **notable variation** between consecutive frames
- Possible short comet-tail artifacts originating from the pleural line in frame 5–6
- This segment displays **shimmering/granular** characteristics → **sliding PRESENT**

### Frames 7–8
- Pleural line becomes **smooth, sharply defined, and static**
- Prominent **horizontal parallel lines** (A-lines) below — unchanged between frames
- Sub-pleural speckle shows **no meaningful variation**
- Classic **stratosphere/barcode pattern** → **sliding ABSENT**

### Frames 9–10
- Return of subtle sub-pleural texture variation
- Pleural line again slightly more granular
- Transitional appearance

---

## Synthesis

| Phase | Frames | Finding |
|-------|--------|---------|
| Sliding present | 4–6 | Textured/shimmering pleural line, speckle variation |
| Sliding absent | 7–8 | Smooth static pleural line, static A-lines |
| Transitional | 1–3, 9–10 | Mixed features |

---

## Conclusion: **BOTH — Lung Point Present** ⚠️

The sequential frames demonstrate an **alternating pattern**: pleural sliding is present in some frames (lung sliding into the scan plane) and absent in others (lung retracting, leaving only air-pleural interface). This **intermittent appearance/disappearance of the sliding sign at a fixed probe position** is the definition of a **lung point** — **pathognomonic for pneumothorax**.

# Lung Ultrasound Sequential Frame Analysis

## Frame-by-Frame Observations

### Frames 1–3 (Early sequence)
- Pleural line appears **relatively smooth and sharply defined**
- Sub-pleural speckle is **uniform with minimal inter-frame variation**
- Horizontal A-lines visible, appearing **static**
- Pattern consistent with **absent sliding** (stratosphere/barcode pattern equivalent in 2D)

### Frames 4–6 (Mid sequence)
- Pleural line becomes **bright, irregular, and textured**
- Multiple **hyperechoic foci** consistent with comet-tail/B-line artifacts originating at the pleural interface
- **Significant inter-frame sub-pleural speckle variation** noted
- Pattern consistent with **sliding present** (seashore equivalent in 2D)

### Frames 7–8 (Late mid sequence)
- Abrupt return to a **smooth, static, featureless pleural line**
- Sub-pleural region becomes **homogeneous and dark**
- Minimal inter-frame variation → **sliding absent** again

### Frames 9–10 (Final frames)
- Partial return of hyperechoic artifacts and speckle variation
- **Transitional appearance** between static and dynamic patterns

## Conclusion: ⚠️ LUNG POINT — **BOTH** patterns present

> This sequential clip demonstrates the **lung point sign** — a cyclical alternation between:
> - **Absent sliding** (pneumothorax zone): smooth static pleural line, static A-lines
> - **Present sliding** (normal aerated lung): shimmering pleural line, comet-tail artifacts, sub-pleural speckle variation

### Clinical Significance
The **lung point is pathognomonic for pneumothorax** (specificity ~100%). It represents the anatomical boundary where the visceral pleura re-contacts the parietal pleura at the edge of the air collection. Its location can estimate pneumothorax size — a more lateral/posterior lung point correlates with larger pneumothorax.

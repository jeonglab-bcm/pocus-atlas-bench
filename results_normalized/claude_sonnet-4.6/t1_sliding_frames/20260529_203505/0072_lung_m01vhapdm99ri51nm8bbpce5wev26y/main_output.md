## 🔍 Conclusion

> **Pleural sliding is PRESENT bilaterally.**

**Supporting evidence:**
1. **B-lines** — multiple comet-tail artifacts originating from the pleural line; by definition, B-lines **travel with the pleural line during respiration**, confirming sliding
2. **Irregular/granular pleural line** — inconsistent with the static, smooth appearance seen in absent sliding
3. **Frame-to-frame sub-pleural speckle variation** — indicates dynamic lung–pleural interface movement
4. **No barcode sign** features identified

**Pathological context (Miliary TB):**
The combination of:
- **Sub-pleural nodules** (small hypoechoic foci at the pleura = granulomata)
- **Multiple B-lines** (interstitial involvement)
- **Preserved lung sliding**

...is the **characteristic LUS pattern of Miliary TB**, distinguishing it from pneumothorax (absent sliding + A-lines) or consolidative TB (tissue-like pattern). Lung sliding is expected to be preserved in miliary disease unless extensive pleural adhesions develop.

# 0035_lung_unexpected-jellyfish

The ultrasound images demonstrate the following findings:

*   **Effusion signs**: There is a large, anechoic (black) space, which is characteristic of a significant **pleural effusion**.
*   **Consolidation signs**: Within the anechoic fluid, there is a visible, echogenic (bright/solid) structure that represents **tissue-like hepatization** of the lung (consolidated or atelectatic lung).
*   **Combined sign**: The dynamic movement of this consolidated lung tissue floating and undulating within the pleural fluid is a classic presentation of the **jellyfish sign**.

**Conclusion:**
*   **plaps = true**
*   **type = "both"**

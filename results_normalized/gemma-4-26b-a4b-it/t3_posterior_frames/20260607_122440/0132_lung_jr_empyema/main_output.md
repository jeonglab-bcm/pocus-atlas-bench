# 0132_lung_jr_empyema

Based on the sequential ultrasound frames, the following observations can be made:

*   **Effusion signs:** A large anechoic (black) area is visible, which is characteristic of a **pleural effusion**. Within this fluid, the consolidated lung tissue appears to be floating, which is consistent with the **jellyfish sign**.
*   **Consolidation signs:** The lung parenchyma exhibits **tissue-like hepatization**, appearing as solid, echogenic tissue that resembles the texture of the liver. This indicates significant lung consolidation.

Since both an effusion and consolidation are clearly visible, the pattern is classified as follows:

**plaps = true**
**type = "both"**

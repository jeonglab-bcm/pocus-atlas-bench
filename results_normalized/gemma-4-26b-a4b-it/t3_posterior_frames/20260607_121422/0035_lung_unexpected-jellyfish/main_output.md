# 0035_lung_unexpected-jellyfish

The ultrasound images demonstrate a clear **PLAPS pattern** involving both pleural effusion and lung consolidation.

**Observations:**
* **Effusion signs:** There is a large anechoic (black) space representing a pleural effusion. Within this fluid, an echogenic mass of lung tissue is seen floating and undulating, which is a classic **jellyfish sign**. The collection is bounded by rib shadows and the pleural line, consistent with a **quad sign**.
* **Consolidation signs:** The floating lung tissue exhibits **tissue-like hepatization**, appearing solid and echogenic like liver parenchyma. The interface between this consolidated lung and the surrounding fluid is irregular, consistent with a **shred sign**.

**Conclusion:**
* **plaps = true**
* **type = "both"**

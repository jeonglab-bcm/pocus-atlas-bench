# Lung Ultrasound Analysis: Right Base

## Frame-by-Frame Observations

**Frames 1-3:**
- A bright pleural line is visible superficially
- Below it, there is a large **anechoic (dark) space** consistent with fluid
- A bright, irregular echogenic structure is visible deep in the field
- The sub-pleural space shows minimal texture change between these early frames

**Frames 4-6:**
- The echogenic structure deep to the fluid becomes more prominent and irregular
- It **changes shape and position** between frames — appearing to undulate
- This is consistent with atelectatic/consolidated lung floating within fluid

**Frames 7-9:**
- The floating lung tissue continues to move/shift configuration
- The "jellyfish sign" is clearly demonstrated — atelectatic lung swaying within the effusion
- Clear motion is present across sequential frames

**Frame 10:**
- Returns to a configuration similar to earlier frames
- The effusion and floating lung are still visible

## Key Findings

| Feature | Observation |
|---------|-------------|
| Anechoic space | Present — **pleural effusion** |
| Floating echogenic tissue | Present — **atelectatic lung** |
| Inter-frame motion | **Significant** — lung tissue moves within fluid |
| Jellyfish/sinusoid sign | **Present** |
| Static A-lines | **Absent** |
| Barcode/stratosphere sign | **Not seen** |

## Conclusion: **Pleural Sliding PRESENT**

This clip demonstrates a **right-sided pleural effusion** with **atelectatic lung tissue moving within the fluid** (jellyfish sign). The clear respiratory-phase motion of the lung tissue across frames confirms active lung movement. While classic visceral-parietal pleural sliding is replaced by fluid separation, the underlying lung mobility is preserved, confirming that sliding (lung movement) is **present**.

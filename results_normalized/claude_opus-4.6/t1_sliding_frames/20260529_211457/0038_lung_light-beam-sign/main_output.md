# Lung Ultrasound Analysis: Frame-by-Frame Assessment

## Frame-by-Frame Observations:

**Frames 1, 5, 6, 8:** The pleural line appears as a bright, shimmering/granular interface. Below the pleural line, there is variation in the sub-pleural speckle pattern. The tissue below shows a textured, granular appearance suggesting lung parenchyma in contact with the chest wall. These features indicate **sliding PRESENT**.

**Frames 2, 3, 4, 7, 9, 10:** In these frames, prominent vertical artifacts extend from the pleural line deep into the image. However, in some of these frames, segments of the pleural line appear more sharply defined and static. The sub-pleural pattern in portions of the image appears more fixed/stratified.

## Key Findings:

| Feature | Observation |
|---------|-------------|
| Pleural line texture | Alternates between granular/shimmering and more static |
| Sub-pleural variation | Dramatic changes between consecutive frames |
| Vertical artifacts (B-lines) | Intermittently present, appearing and disappearing |
| Transition zone | Visible point where sliding characteristics change |

## Conclusion: **BOTH (Lung Point)**

This clip demonstrates a **lung point** — a transition zone where:
- **Sliding is intermittently present** (granular pleural line, B-lines, sub-pleural variation)
- **Sliding is intermittently absent** (static segments)

The alternating pattern of lung contact with the chest wall across respiratory cycles is pathognomonic for a **pneumothorax** with a lung point, representing the boundary between aerated lung and free pleural air. This is a 100% specific sign for pneumothorax.

# Lung Ultrasound Analysis: Frame-by-Frame Assessment

## Frame-by-Frame Observations

### B-mode (Lower panels):
- A bright **pleural line** is visible at approximately 1.5-2 cm depth across all frames
- **A-lines** (horizontal reverberation artifacts) are visible below the pleural line in several frames
- Comparing consecutive frames, there is **variation in the sub-pleural speckle pattern** — the granular texture below the pleural line changes subtly between frames
- The pleural line itself appears **textured/shimmering** rather than smooth and static

### M-mode (Upper panels):
- **Above the pleural line**: Consistent horizontal, parallel stratified lines representing the static chest wall — this is expected and normal
- **At the pleural line**: A bright hyperechoic horizontal line at ~2 cm depth
- **Below the pleural line**: A **granular, sandy texture** is visible that contrasts sharply with the parallel lines above — this is the classic **"seashore sign"**
- As the M-mode tracing builds across frames 1→10, the granular pattern below the pleural line remains consistent throughout the time axis, with no segments of barcode/stratosphere pattern

## Key Findings Summary

| Sign | Present? |
|------|----------|
| Seashore sign (M-mode) | ✅ Yes |
| Granular sub-pleural speckle variation | ✅ Yes |
| Barcode/stratosphere sign | ❌ No |
| Static pleural line | ❌ No |
| Lung point (transition) | ❌ No |

## Conclusion

**Pleural sliding is PRESENT.**

The M-mode demonstrates a clear **seashore sign** — horizontal lines above the pleural line (chest wall) transitioning to a granular/sandy pattern below (moving lung). The B-mode confirms subtle frame-to-frame variation in sub-pleural texture consistent with normal visceral-parietal pleural interaction. There is no evidence of barcode sign or lung point.

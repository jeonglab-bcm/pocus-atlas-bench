# Lung Ultrasound Analysis: Sequential Frame Assessment

## Frame-by-Frame Observations

**Frames 1, 5, 6, 8:**
- The pleural line appears relatively bright but smooth
- Sub-pleural area is mostly dark/anechoic
- Minimal vertical artifacts
- The speckle pattern below the pleural line appears relatively static

**Frames 2, 3, 4, 7, 9, 10:**
- The pleural line appears more textured/granular
- Prominent **B-lines/vertical artifacts** originate from the pleural line and extend downward
- The sub-pleural speckle pattern shows clear variation compared to adjacent frames
- Tissue-like pattern appears below the pleural line (suggesting aerated lung in contact with chest wall)

## Key Findings

| Feature | Observation |
|---------|-------------|
| Pleural line character | Alternates between static/smooth and shimmering/granular |
| B-lines | Present intermittently (appear and disappear across frames) |
| Sub-pleural speckle | Changes dramatically between frame groups |
| Transition | Visible shift between dynamic and static patterns at the same location |

## Conclusion: **BOTH (Lung Point)**

This clip demonstrates a **lung point** — the pathognomonic sign of **pneumothorax**. There is a visible alternation between:
- **Sliding present:** Granular pleural line with B-lines and dynamic sub-pleural pattern
- **Sliding absent:** Smooth, static pleural line with no sub-pleural variation

This represents the boundary where the partially collapsed lung intermittently contacts the chest wall during respiration, confirming the presence and delineating the extent of a pneumothorax.

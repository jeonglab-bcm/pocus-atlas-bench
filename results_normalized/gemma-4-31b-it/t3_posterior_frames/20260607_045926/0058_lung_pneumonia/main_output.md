# 0058_lung_pneumonia

The ultrasound frames show a posterior lung zone with the following findings:

*   **Effusion:** There is a prominent anechoic (black) space, which is characteristic of a pleural effusion.
*   **Consolidation:** Below the fluid collection, the lung parenchyma has lost its normal aerated appearance and instead exhibits a tissue-like, echogenic texture, resembling the liver (**hepatization**). Within this consolidated area, there are multiple hyperechoic punctate and linear foci, which are **air bronchograms**. The border between the consolidated lung and the adjacent fluid/aerated areas is irregular, representing the **shred sign**.

Since both pleural effusion and alveolar consolidation are present, this is a PLAPS pattern.

**Conclusion:**
- plaps = true
- type = "both"

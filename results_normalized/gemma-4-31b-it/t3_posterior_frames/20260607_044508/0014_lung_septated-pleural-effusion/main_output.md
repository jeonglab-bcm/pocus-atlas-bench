# 0014_lung_septated-pleural-effusion

The ultrasound images show a large anechoic (black) area representing a significant pleural effusion. Within this fluid collection, there are floating, undulating hyperechoic structures that move with respiration, which is a classic representation of the **jellyfish sign**. This sign indicates atelectatic or consolidated lung tissue floating within the pleural fluid.

Because there is both a clear fluid collection (effusion) and floating consolidated lung tissue, this represents a PLAPS pattern.

- **plaps = true**
- **type = "both"**

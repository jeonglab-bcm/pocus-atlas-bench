# 0030_lung_parapneumonic-effusion-with-b-lines

The ultrasound frames show a large anechoic (black) space in the posterior dependent lung zone, which is diagnostic of a pleural effusion. Within this fluid collection, there is a fragmented, echogenic mass of lung tissue that is floating and undulating with respiration, which is the characteristic "jellyfish sign." This floating lung tissue exhibits tissue-like hepatization, appearing solid and similar to liver texture, which indicates alveolar consolidation.

Conclusion:
- plaps = true
- type = "both"
